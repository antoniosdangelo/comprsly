COMPRSLY - ACKNOWLEDGEMENTS AND LICENCES
========================================

Comprsly is built on open source work. The libraries below ship inside
this installer, so their notices travel with it, which is what these
licences ask for. (The AI model is the one exception: it is downloaded
separately, see its own section.) Versions are the exact ones bundled in
this build.


THE LOCAL AI MODEL
------------------
Qwen2.5-1.5B-Instruct  -  Apache License 2.0
    Copyright (c) Alibaba Cloud / the Qwen team.
    https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct

    The AI model is a quantized (int4, ONNX) build of Qwen2.5-1.5B-Instruct,
    ~975 MB. It is NOT bundled in this installer; the app downloads it once,
    on first use of the "Make it Concise" step, directly from the source repo
    below. Its use is governed by Apache 2.0. Nothing you type is uploaded;
    this is a one-time model-file download only.

    Quantized ONNX conversion published by the community as
    khanuckaeff/Qwen2.5-1.5B-Instruct-Olive-Onnx, verified against the
    official Qwen release before bundling: identical vocabulary (151,643
    entries), identical merge rules (151,387), identical special tokens, and
    matching architecture parameters.

    The model runs entirely on your machine. Nothing you type is ever
    sent anywhere; the model download above is the only network activity
    the app can perform, and it only ever brings files down to you.

SPELL CHECKING
--------------
Spelling uses the Windows spell-checking API built into your copy of
Windows, the same engine Edge and Word use. No dictionary is bundled and
none is sent anywhere.


PRIVACY
-------
There is no telemetry, no account, no cloud processing and no analytics.
Your text, your prompts and the tokens you save never leave this machine.
The only network request Comprsly can ever make is the one-time, optional
AI-model download you trigger yourself; after that the model runs fully
locally, which is the whole point of the product.


Full licence texts are available at each project's address above.
